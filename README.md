# 제2차 세계대전 유럽 전선 — 지구본 애니메이션 (1939.9.1 ~ 1945.5.25)

지구본(정사도법) 위에서 유럽·북아프리카·소련 전선이 날짜별로 움직이는 애니메이션입니다.
1939년 9월 1일 독일의 폴란드 침공부터 1945년 5월 25일 유럽 최후의 전투로 꼽히는
오자크 전투(보스니아) 종결까지 하루 단위로 재생됩니다.

- **영상**: `video/ww2_europe_fronts_1939-1945.mp4` (1920×1080, 30fps, 약 3분 20초, 초당 11일 진행)
- **인터랙티브 버전**: `index.html` — 단일 파일이며 인터넷 연결 없이 브라우저로 열 수 있습니다.
  - 스페이스: 재생/일시정지 · ←/→: 한 달 이동 · 하단 타임라인 클릭: 해당 날짜로 이동 · 재생 속도 선택
  - `index.html?t=1942-11-19` 처럼 시작 날짜를 지정할 수 있습니다.

## 표시 내용

| 색 | 의미 |
|---|---|
| 진한 파랑 | 나치 독일 및 점령지 |
| 연한 파랑 | 추축 동맹국 (이탈리아·헝가리·루마니아·불가리아·핀란드·슬로바키아 등) |
| 회보라 | 비시 프랑스 |
| 초록 | 연합국 및 해방 지역 |
| 빨강 | 소련 및 동맹군 (1944년 이후 루마니아·불가리아·유고 해방구 포함) |
| 베이지 | 중립국 |
| 주황 발광선 | 교전 중인 세력 사이의 전선 (교전 관계는 날짜별로 판정: 독소 개전 전 독·소 경계는 전선이 아님 등) |

주요 전역: 폴란드 침공, 겨울전쟁, 노르웨이, 프랑스 전역, 북아프리카(나침반·가잘라·엘알라메인·횃불·튀니지),
발칸·크레타, 바르바로사, 레닌그라드 포위, 모스크바, 청색 작전과 캅카스, 스탈린그라드, 쿠르스크,
시칠리아·이탈리아(구스타프선·안치오·고딕선), 노르망디·드라군, 바그라티온, 바르샤바 봉기,
벌지 전투, 비스와–오데르, 베를린 전투, 그리고 각종 포위망(키예프·뱌지마·스탈린그라드·코르순·쿠를란트·부다페스트·브레슬라우·루르 등).
화면 왼쪽에는 130여 개의 주요 사건이 날짜와 함께 표시되고, 지도 위 해당 지점에 표식이 나타납니다.

## 정확도에 관하여

- 전선은 주요 시점(동부전선 약 50개, 서부전선 약 20개 등)의 위치를 사람이 직접 좌표로 입력하고,
  그 사이를 선형 보간한 **근사치**입니다. 실제 전선은 보간 구간 사이에서 더 급격하거나 불규칙하게 움직였습니다.
- 국경선은 1938년 기준(aourednik/historical-basemaps)이며, 해안선은 Natural Earth 1:50m 입니다.
- 유고슬라비아 파르티잔 해방구, 그리스·크레타 잔존 독일군, 소규모 대서양 요새 등은 단순화되어 있습니다.

## 구조

```
src/history.js      역사 데이터: 국가별 지배 세력 변화, 전선 키프레임, 포위망, 사건, 카메라
src/app.js          렌더러 (d3-geo 정사도법, 캔버스, 전선 자동 검출, HUD)
src/template.html   페이지 틀 / 재생 컨트롤
src/geo-data.js     생성된 지리 데이터 (tools/prepare-geo.mjs + tools/fit-borders.py)
tools/build.mjs     모든 것을 단일 index.html 로 묶음 (폰트·d3 포함)
tools/render-video.mjs  헤드리스 Chromium + ffmpeg 로 MP4 렌더링
tools/snap.mjs      특정 날짜 스틸 이미지 렌더링 (검수용)
sources/            원본 지리 데이터
```

다시 빌드하기:

```bash
npm install
node tools/prepare-geo.mjs && python3 tools/fit-borders.py   # 지리 데이터 (shapely 필요)
node tools/build.mjs                                          # index.html
node tools/render-video.mjs                                   # video/*.mp4 (playwright, ffmpeg 필요)
node tools/snap.mjs out/ 1941-12-05 1944-06-06                # 스틸 이미지
```

전선 렌더링 방식: 각 프레임마다 세력 영역을 저해상도 ID 캔버스에 그린 뒤, 날짜 기준으로
서로 교전 중인 세력(추축 ↔ 서방 연합국, 추축 ↔ 소련(1941.6.22 이후) 등)이 맞닿은 육지 픽셀을
찾아 발광선으로 그립니다. 따라서 해안·중립국 경계에는 전선이 그려지지 않습니다.
